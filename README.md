# Aircraft Spotter Radar

## Project

Aircraft spotting assistant for aviation photographers and plane spotters.

## Initial Feature

Home Airport Daily Spotlight.

## Current Status

Early development / MVP.

## Intended Product Direction

The product will support airport traffic discovery, special aircraft highlighting, aircraft rarity, special liveries, aircraft watchlists, photography history, notifications, airport operations intelligence, and future runway and spotting forecasts.

## Repository Structure

- `apps/` — application clients
- `services/` — backend services
- `packages/` — shared domain and business logic
- `docs/` — technical and feature documentation
- `scripts/` — development and data utilities
